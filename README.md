# Lernprogramm Ökologie

Der Ordner enthält das zusammengefasste Lernprogramm mit den Themen:

- Ökologische Potenz
- Ökologische Nische

## Lokal öffnen

Die Datei `index.html` im Browser öffnen. Die Unterordner und Dateien dürfen dabei nicht verschoben oder umbenannt werden.

## Mit GitHub Pages teilen

1. Den gesamten Inhalt dieses Ordners in das Stammverzeichnis eines GitHub-Repositories hochladen.
2. Im Repository **Settings → Pages** öffnen.
3. Unter **Build and deployment** die Option **Deploy from a branch** wählen.
4. Den Branch **main** und den Ordner **/(root)** auswählen.
5. Mit **Save** bestätigen.

Nach der Veröffentlichung führt die Startseite zu beiden Lernprogrammen.
